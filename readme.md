# Выполнено и планирование
Изначально планировалось реализовать UI для приложения.
Однако после оценки моделей приложения я понял, что времени под UI у меня не останется и лучше всего будет сфокусироваться на программных интерфейсах, нежели пользовательских. 

**Насчет Нормальных форм:**
В таблице *appointments* есть 2 внешних ключа. Id доктора и id специальности доктора.

У меня предположение, что у доктора может быть много квалификаций и их стоит вынести как отдельную таблицу *doctor_speciality*. 
Для соответствия НФ больше чем 3, следовало было заменить 2 ключа в *appointments* на 1 из *doctor_speciality*.
Не сразу пришло мне это в голову,  т.к. добавил эту таблицу, когда уже реализовывал логику.
